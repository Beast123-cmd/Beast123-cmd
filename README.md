## Selected Projects

### Medico.ai | AI-Assisted Clinical Triage Platform

A full-stack healthcare application that connects patient symptom intake with structured AI-assisted triage and clinician-facing case review.

- Developed a patient-facing interface for multi-turn symptom collection and case history using **Next.js**.
- Built a **FastAPI** AI service to manage follow-up questions, assign urgency levels, and generate structured case summaries for review.
- Used **NestJS** to handle application APIs and JWT authentication, with **Supabase/PostgreSQL** for data persistence.
- Integrated **Ollama** for local LLM inference and explored privacy-conscious processing of sensitive medical information.

**Technologies:** Next.js, NestJS, FastAPI, PostgreSQL, Supabase, Ollama  
*Private repository. This is an experimental engineering project, not a clinically validated diagnostic system.*

### ResearchSync | Research Publication and Accreditation Platform

An institutional platform that streamlines faculty publication submission, research metadata extraction, verification, administrative review, and reporting.

- Designed a document processing pipeline using **Docling** and **PyMuPDF** to extract publication information from PDFs, with optional local LLM enrichment.
- Incorporated a human-in-the-loop workflow where faculty can verify and correct extracted details before submission.
- Built around **FastAPI, SQLAlchemy, and PostgreSQL** for APIs, structured records, validation, and administrative operations.
- Uses **React** for faculty and administrator interfaces and **OpenPyXL** to generate structured Excel reports.

**Technologies:** React, FastAPI, PostgreSQL, Supabase, Docling, PyMuPDF, OpenPyXL  
*Private repository; technical overview available on request.*
